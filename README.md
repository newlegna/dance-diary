# Dance Diary

See your dance progress in motion. A private-first web MVP for beginner hip hop dancers to record short practice clips, compare Day 1 vs Day 30 side-by-side, and export glow-up reels.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in Chrome for the best camera/export support.

## MVP features

- Create 7/14/30-day dance journeys with hip hop templates
- Record or upload 10–20 second practice clips
- Progress timeline with day labels and notes
- Side-by-side synced comparison with speed and mute controls
- Export vertical 9:16 progress videos to your device
- Private-by-default journeys (IndexedDB local storage)
- Lightweight community feed preview

## Tech stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- IndexedDB for clips and video blobs
